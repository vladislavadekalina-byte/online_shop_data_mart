# Аналитический слой интернет-магазина

Проект преобразует сырые данные интернет-магазина в аналитические витрины
с использованием dbt.

## Слои данных

Данные организованы в 3 слоя:

- **staging**: подготовка и стандартизация исходных данных
- **intermediate**: промежуточные расчеты, объединение таблиц и аналитическое дерево
- **marts**: итоговые аналитические ветрины

## Витрины проекта

В проекте 5 витрин:

- `fct_orders`: информация о заказах и платежах
- `fct_order_items`: товарные позиции заказов
- `dim_products`: товары и их категории
- `dim_customers`: информация о покупателях
- `dim_dates`: календарь по датам

## Проверка качества данных

Для проверки корректности составленных таблиц и представлений используются generic и singular тесты.

Витрина `fct_order_items` использует инкрементальную загрузку новых товарных позиций.
